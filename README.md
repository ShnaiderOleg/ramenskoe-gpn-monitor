# Монитор бензина Газпромнефть — Раменское

Приложение каждые 10 минут получает `https://www.tboo.ru/gpn/data.json`, выбирает АЗС Газпромнефти в городе Раменское, а также расположенную рядом АЗС №194 (в источнике — Сафоново), и отслеживает:

- АИ-92 (`92`);
- АИ-95 (`95`);
- АИ-95 G-Drive (`G-95`).

При переходе марки из состояния «нет» в «есть» подписанным браузерам отправляется Web Push. Первый запуск только запоминает исходное состояние и не рассылает старые события.

## Установка в Windows

Откройте PowerShell в папке приложения и выполните:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

Затем откройте в Chrome или Edge:

```text
http://127.0.0.1:8080
```

Нажмите **«Включить уведомления»**, разрешите их в браузере и воспользуйтесь кнопкой **«Отправить тестовый push»**.

`localhost` считается браузерами безопасным контекстом, поэтому HTTPS для локального использования не требуется. Python-приложение должно оставаться запущенным. Доставка при полностью закрытом браузере зависит от разрешения браузеру работать в фоне.

## Автозапуск

Для постоянной работы добавьте запуск `python app.py` в Планировщик заданий Windows или установите приложение как службу через NSSM/WinSW. Не запускайте одновременно несколько экземпляров с одной папкой данных.

## Настройки

Параметры задаются переменными окружения:

```powershell
$env:POLL_INTERVAL_SECONDS = "600"
$env:CITY_NAME = "Раменское"
$env:DATA_URL = "https://www.tboo.ru/gpn/data.json"
$env:VAPID_SUBJECT = "mailto:you@example.com"
python app.py
```

Состояние, подписки и автоматически созданный VAPID-ключ хранятся в `instance/`. Не удаляйте VAPID-ключ после подписки браузеров: при его смене потребуется подписаться заново.

## Важное ограничение

Источник неофициальный, а его данные могут поступать с задержкой. Приложение не считает исчезновение АЗС из ответа подтверждением отсутствия топлива, но использует опубликованный источником флаг наличия для найденных станций.
